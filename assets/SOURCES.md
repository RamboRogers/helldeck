# Embedded catalog

See the [warbond coverage audit](WARBOND-AUDIT.md) for additions beyond the base table, their sources and the reason the original importer missed them.

Codes: factual sequences transcribed from [HellStrat’s input table](https://hellstrat.com/helldivers-2-stratagem-list). Cross-reference for Hellbomb, SEAF Artillery, flag, seismic probe, prospecting drill, and common support: [community dataset](https://gist.github.com/nvigneux/ad636966e36277fe6cb98ad8afff1fcc). In this [export of game settings](https://github.com/shalzuth/HelldiversData/blob/fc22b64f9d7783bbb6869542715cc1ec8a3b8f4c/data/settings/generated_stratagem_settings.json), `StratagemType_DropoffHellbomb`, `StratagemType_SeismicProbe`, `StratagemType_ProspectingDrill`, `StratagemType_DropoffCargoContainer`, `StratagemType_UploadDiscovery` and `StratagemType_EagleRearm` also match the corresponding catalog codes. The game remains authoritative. This is a snapshot, not a live inventory; only entries with paired artwork are enabled. SSSD Delivery is deliberately not mapped: sources disagree on the sequence and the icon set lacks a matching asset. Portable Hellbomb (loadout) is not the mission Hellbomb.

The atlas rasterizes [nvigneux’s community SVG artwork](https://github.com/nvigneux/Helldivers-2-Stratagems-icons-svg/tree/2fe1d2ceb5397a3b14849afe43a14feb2f21ac58). Upstream invites use in projects; this local build does not claim ownership or grant a license for redistribution of game art. Confirm terms before publishing. No game assets, scripts, or data are downloaded at runtime. The 111 source SVGs are in `source/icons/`, the copied input table is `source/stratagems.md`, and reviewed additions are in `catalog-overlay.json`. From the project root, `python3 tools/import_assets.py` rebuilds `catalog.json` and `atlas.png` using only these files (Pillow and `rsvg-convert` required). It reports table rows that have no paired mission art; they are not enabled. The current atlas has 109 occupied tiles; Prospecting Drill and Hive Breaker Drill have identical artwork but separate catalog IDs.
