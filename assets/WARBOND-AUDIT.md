# Warbond call-in audit — 2026-11-24

Scope: **selectable stratagems**, not primary/secondary weapons, armor, throwables, boosters, skins, or per-player ownership. Compared HellDeck's previous release against the current wiki reward and input tables, the pinned icon tree, and an independently published transcription of the codes.[1][2][3] Names and arrow sequences are paired with specific art; an alias is not a guess based on a similar icon.

| Source | Missing from previous release | Verified sequence (U/D/L/R) |
|---|---|---|
| Scope of Authority[1][4] | AMW-20 Apex; LAS-44 Nova | `DLLUDL`; `DLRDD` |
| Siege Breakers[1][5] | CQC-20 Breaching Hammer; EAT-411 Leveller; GL-28 Belt-Fed Grenade Launcher | `DLRLU`; `DDLUD`; `DLULUU` |
| Entrenched Division[2][6] | A/GM-17 Gas Mortar Sentry | `DURDL` |
| Urban Legends[2][7] | A/FLAM-40 Flame Sentry | `DURDUU` |

All seven are now both selectable and eligible for visual Sync. Outside the warbond gaps, the same comparison surfaced the M-102 Gunner FRV (formerly Fast Recon Vehicle), M-104 Incinerator FRV, and TD-110 Maelstrom; these now have entries too.[2] This is a coverage snapshot, not a claim about unreleased content or every mission-specific objective.

**Import failure:** the old importer started only with HellStrat's table and silently discarded rows without an exact artwork-name match. The Scope of Authority pair had art but no input-table row. For Siege Breakers the table used weapon names while the art used `CQC-20`, `EAT-411` and `GL-28`. A reviewed overlay now supplies codes and explicit art names; a new unpaired loadout row fails the import rather than vanishing. Runtime remains offline.
